## 🚀 Основные возможности



* **Интерактивное колесо фортуны**: Плавное вращение (conic-gradient, CSS-трансформации, requestAnimationFrame), звуковая имитация тиков стрелки и динамическое разделение на сектора.

* **Умный подбор иконки**: Автоматическое сопоставление текстового названия задачи с визуальным эмодзи (🍕, 🧹, 🗑️, 🪣, 👕 и др.).

* **Справедливая очередь (Smart Queue)**: Алгоритм рандомизации исключает повторное выпадение дел одному и тому же участнику подряд.

* **Управление списками**: Добавление, редактирование и удаление участников (до 8 человек) и задач (до 12 ячеек).

* **Адаптивный дизайн и Космический визуал**: Глубокая космическая тема, эффект матового стекла (`backdrop-filter`) и поддержка мобильных устройств.

* **Визитка команды**: Раздел с QR-кодами участников для быстрой связи через Telegram.



---



## 🛠 Технологический стек



* **Разметка**: HTML5 (семантичные теги, SVG-спрайты)

* **Стилизация**: CSS3 (Grid/Flexbox, CSS Custom Properties, Glassmorphism)

* **Логика**: Vanilla JavaScript (DOM API, Intersection Observer, Canvas/Math рандомизация)

* **Сборка и запуск**: Статические веб-технологии без тяжелых фреймворков и сборщиков.

## ⚙️ Запуск проекта локально



1. Склонируйте репозиторий или откройте папку проекта в вашей IDE (например, WebStorm / PyCharm).

2. Убедитесь, что все ассеты находятся в папке `assets/` (включая иконки и QR-коды в `assets/qr/`).

3. Запустите файл **`index.html`** через встроенный локальный сервер среды разработки (или откройте его напрямую в любом современном браузере).
